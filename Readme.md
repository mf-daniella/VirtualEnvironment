## how to setup virtual environment

create virtual environment by running the following command in the current working directory (project root)
```
python -m venv env 
```

How to activate! the virtual environement:
Format: <env_name>\Scripts\activate
```
.env\Scripts\activate
```

How to install a python package:
Format: pip install <package_name>
```
    pip install numpy
```

How to create a requirements.txt:
```
pip freeze > requirements.txt
```

How to install pacakges from requirements.txt
```

pip install -r requirements.txt
```
